## 2026-08-04 Git & GitHub 学习心得

### Git 是什么？

Git 是一个**版本控制工具**，可以理解成游戏的"存档系统"——每次提交（commit）就是一个存档点，出问题了随时可以回退。

### 常用命令

| 命令 | 作用 |
|------|------|
| `git init` | 初始化一个本地仓库 |
| `git add .` | 把所有修改加到暂存区（相当于选中要存档的内容） |
| `git commit -m "说明"` | 提交一个版本（相当于点"保存"按钮） |
| `git status` | 查看当前仓库状态 |
| `git log` | 查看提交历史 |
| `git push` | 把本地代码推送到远程仓库（比如 GitHub） |
| `git pull` | 从远程仓库拉取最新代码到本地 |
| `git clone <地址>` | 克隆一个远程仓库到本地 |

### GitHub 是什么？

GitHub 是一个**代码托管平台**，可以理解成代码的"网盘"——把你的本地仓库放到云端，方便备份、分享、和他人协作。

### 我的理解

```
本地写代码 → git add → git commit → git push → GitHub 云端
                            ↑
                      存档到本地仓库       ↑
                                    同步到远程仓库
```

### 小提醒

- commit 信息尽量写清楚改了什么，方便以后回顾
- 养成经常 commit 的习惯，不要攒一大堆才提交一次
- 先 add 再 commit，两步走，别忘了
